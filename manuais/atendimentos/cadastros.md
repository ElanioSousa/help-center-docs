# Cadastros

> 📌 **Sobre os Cadastros**
> 
> Aqui você gerencia todas as configurações base e tabelas auxiliares que alimentam o seu módulo de Atendimentos.

## Opções de Cadastro

Escolha uma das funcionalidades abaixo para ver o passo a passo detalhado:

* <a href="#" onclick="carregarManual('atendimentos/cadastros-etiquetas')"><b>Etiquetas</b></a>
Aprenda a criar e gerenciar etiquetas para classificar a temperatura e o status dos seus leads.

* <a href="#" onclick="carregarManual('atendimentos/cadastros-motivos-desistencia')"><b>Motivos de Desistência</b></a>
Cadastre e gerencie os motivos padronizados para quando uma negociação for perdida ou cancelada.

* <a href="#" onclick="carregarManual('atendimentos/cadastros-origem-leads')"><b>Origem de Leads</b></a>
Configure os canais de entrada para identificar de onde seus clientes estão vindo (ex: Instagram, WhatsApp).

* <a href="#" onclick="carregarManual('atendimentos/cadastros-checklist')"><b>Checklist</b></a>
Crie listas de verificação e etapas para padronizar os processos de atendimento da sua equipe.

* <a href="#" onclick="carregarManual('atendimentos/cadastros-opcionais')"><b>Opcionais</b></a>
Gerencie o cadastro de itens opcionais e características que podem ser vinculadas aos veículos ou propostas.

* <a href="#" onclick="carregarManual('atendimentos/cadastros-grupo')"><b>Grupo</b></a>
Organize e classifique dados criando grupos personalizados para facilitar a emissão de relatórios.
