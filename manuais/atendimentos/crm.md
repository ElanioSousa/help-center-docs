# Cadastro de Novo Atendimento

O registro de um novo atendimento é a etapa inicial para inserir um cliente no seu funil de vendas do CRM. Preencha os dados com atenção para garantir um histórico completo e preciso da negociação desde o primeiro contato.


Abaixo está a interface da tela de cadastro com a explicação detalhada de cada campo correspondente aos números indicados na imagem.

![Tela Novo Atendimento Numerada](./assets/img.png)

### Detalhamento dos Campos

**Seção: Cliente**
* **1 - Tipo de Pessoa:** Define se o cadastro será feito utilizando os dados de uma Pessoa Física (CPF) ou Pessoa Jurídica (CNPJ).
* **2 - Nome (\*):** Campo obrigatório para inserir o nome completo ou a razão social do cliente.
* **3 - CPF:** Campo para registro do Cadastro de Pessoa Física do cliente.
* **4 - RG:** Campo para o número do documento de identidade do cliente.
* **5 - Telefone Celular (\*):** Campo obrigatório para o contato principal do cliente (recomendado utilizar o número de WhatsApp).
* **6 - Email:** Campo para registrar o endereço de correio eletrônico do cliente.
* **7 - Empresa (\*):** Menu suspenso obrigatório para selecionar a qual unidade ou filial da empresa este atendimento será vinculado.
* **8 - Negociador (\*):** Menu suspenso obrigatório para definir o vendedor ou consultor que ficará responsável por este cliente.
* **9 - Tipo (\*):** Menu suspenso obrigatório para classificar a intenção primária do atendimento (ex: Compra, Venda, Troca).
* **10 - Origem (\*):** Menu suspenso obrigatório para indicar por qual canal o cliente chegou até a empresa (ex: WhatsApp, Instagram, Balcão).

**Seção: Registro**
* **11 - Trocar Fase:** Permite que o atendimento já inicie em uma etapa mais avançada do funil de vendas, pulando as fases iniciais. Seu preenchimento é opcional.
* **12 - Bloco de Fluxo de Loja:** Grupo de campos utilizado para clientes que estão presencialmente na loja. Ao marcar a caixa **"Registrar Fluxo Loja"**, o sistema permite registrar a **"Data/Hora"** exata da visita e selecionar o **"Motivo do Fluxo"**.

**Seção: Veículo**
* **13 - Placa:** Campo para inserir a placa do veículo envolvido na negociação. Utilize o botão **"Consultar"** para buscar os dados do veículo automaticamente no sistema.
* **14 - Tipo Veículo:** Menu suspenso para definir a categoria do veículo (ex: Carro, Moto, Caminhão).
* **15 - Veículo sem FIPE:** Caixa de marcação utilizada para veículos que não constam na base oficial da Tabela FIPE (ex: veículos de coleção ou exclusivos).
* **16 - Marca:** Campo de texto para informar a fabricante ou montadora do veículo (ex: Fiat, Honda).
* **17 - Modelo:** Campo de texto para especificar o modelo e a versão do veículo.
* **18 - Ano Fab.:** Campo para registrar o ano em que o veículo foi fabricado.
* **19 - Ano Mod.:** Campo para registrar o ano do modelo do veículo lançado pela montadora.

**Seção: Precificação**
* **20 - Bloco de Precificação:** Área para análise financeira do veículo envolvido. Exibe o **"Valor FIPE"** de mercado, a **"Média Cliente"** (valor de venda para consumidor final), a **"Média Lojista"** (valor de repasse) e um campo para estipular a **"Previsão Rentabilidade"** da negociação.
