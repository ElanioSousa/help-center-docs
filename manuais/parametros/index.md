>💡 **Sobre este Módulo**
>
> ℹ️ **Objetivo**: O menu *Parâmetros* permite a personalização, configuração e adaptação do sistema às necessidades específicas de seus usuários ou do ambiente onde será utilizado. Eles funcionam como "ajustes" ou "regras" predefinidas que determinam o comportamento do sistema, garantindo eficiência, conformidade e usabilidade.

## Itens do menu:

* <a href="#" onclick="carregarManual('parametros/empresas')"><b>Empresas</b></a>
Utilize o recurso de parâmetro para visualizar as empresas cadastradas e realizar a edição dos parâmetros, configurações e permissões das empresas.
* <a href="#" onclick="carregarManual('parametros/lojistas')"><b>Lojistas</b></a>
Utilize este recurso para visualizar a relação de lojistas e seus status, bem como criar novos cadastros de usuários e realizar ações de edições. 
* <a href="#" onclick="carregarManual('parametros/usuarios')"><b>Usuários</b></a>
A tela de visualização e cadastro de usuários é uma interface desenvolvida para gerenciar informações relacionadas a usuários no sistema.
* <a href="#" onclick="carregarManual('parametros/extrato-creditos')"><b>Extrato de créditos</b></a>
Extrato de Créditos permite acompanhar os créditos disponíveis, utilizados e lançados no sistema.
* <a href="#" onclick="carregarManual('parametros/integracao-whatsapp')"><b>Integração WhatsApp</b></a>
Permite cadastrar e gerenciar seus contatos integrados ao sistema.
