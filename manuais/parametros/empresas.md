Utilize o recurso de parâmetro para visualizar as empresas cadastradas e realizar a edição dos parâmetros, configurações e permissões das empresas.

O caminho para **Empresas** pode ser acessado pelo menu Parâmetros > Empresa

![image.png](./assets/parametros-image.png)

## Filtro:

Na tela inicial de Empresa, as empresas cadastradas poderão servisualizadas, bem como o recurso de Consultar empresa para buscas mais refinadas.

Para realizar buscas de empresas clique no campo consultar e digite o nome da empresa, em seguida, clique em **consultar** para o sistema efetuar as buscas:
 
![image.png](./assets/parametros-image-1.png)

1. **Consultar Empresa**: Descreva nome da empresa
2. **Consultar:** Clique em consultar para o sistema realizar as buscas. 

## Botão Editar

![image.png](./assets/parametros-image-2.png)

Na tela Inicial, coluna ações é possível realizar edição aos parâmetros as empresas listadas clicando no ícone de edição conforme demostrado abaixo.

![chrome_OHJyqCqlao.gif](./assets/chrome_OHJyqCqlao.gif)

Ao clicar no ícone de edição será direcionado a tela de configurações de parâmetros. Neste tela será exibido tem abas, sendo, **Geral, Atendimento e Operação**.

Abaixo será detalhado a utilização de cada aba. 

![image.png](./assets/parametros-image-3.png)

**Geral**

Neste campo deve ser utilizado pelo gerente/responsável 

![image.png](./assets/parametros-image-4.png)

 1. **Gerente**: Indique o gerente.

1. **Salvar:** Clique em salvar para o sistema gravar alteração. 

**Atendimento**

Deve ser utilizado para as parametrizações do atendimentos.

![image.png](./assets/parametros-image-5.png)

1. **Liberar ‘Pedido’ para Recepcionista:** Selecione este campo para que os pedidos sejam exibidos as recepcionistas.
2. **Exibir endereço no detalhe da oferta:** Selecione este campo para exibir o endereço da empresa junto as ofertas.
3. **Exibir negociador no detalhe da oferta:** Selecione este campo para exibir o negociador na oferta.
4. **Mensagem Whatsapp:** Descreva o texto para enviar nas mensagem de do aplicativo Whatsapp.
5. **Cancelar:** Clique em cancelar caso deseje cancelar as edições.
6. **Salvar:** Clique em salvar para gravar as alterações.

**Operação**
Deve ser utilização para configuração das operações do sistema.
****

![image.png](./assets/parametros-image-6.png)

1. **Ativar integração financeiro:** Seleciona este campo para ativar a integração financeira. Ao selecionar este campo o sistema parametriza a automação vinculada ao financeiro.
2. **Tipo despesa pagamento cliente:** Indique o tipo despesa pagamento cliente para ficar parametrizado como principal.
3. **Tipo despesa recebimento lojista:** Indique tipo despesa recebimento lojista para ficar parametrizado como principal.
4. **Conta padrão lançamentos:** Indique conta padrão lançamentos para ficar parametrizado como principal.
5. **Incremento dias de vencimento despesas(D+X):** Informe o numero de dias a vencer para que o sistema calcule automaticamente com base na data informada e já indique a data futura do vencimento.
6. **Website :** Indique Website para ser exibido.
7. **Procuradores:** Indique o procurador responsável. 
8. **Porcentagem de Comissão:** Indique a porcentagem de Comissão para que o sistema calcule automaticamente.
9. **Taxa Perícia Comprador:** Informe o valor de taxa Perícia Comprador.
10. **Taxa Perícia Proprietário:** Informe o valor Taxa Perícia Proprietário.
11. **Dia vcto. perícia:** Informe dia vencimento da perícia
12. **Forma pgto. perícia:** Informe a forma de pagamento da perícia.
13. **Tipo despesa perícia:** Informe tipo de despesa perícia.
14. **Fornecedor perícia:** Informe o fornecedor da perícia. 

> 💡
>
> Neste campo a um atalho denominado “Cadastrado Novo”. Clique <a href="#" onclick="carregarManual('financeiro/cadastros-fornecedor')">AQUI</a> para ser direcionado passo a passo para criação de um novo cadastro de fornecedor.

1. **Valor de custo perícia:** Informe o valor de custo perícia. 
2. **Observação despesa operação obrigatório:** Selecionando este campo o sistema irá tonar obrigatório registrar observação nas despesas de operação.
