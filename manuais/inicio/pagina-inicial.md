# Página Inicial do Sistema

#### **Página inicial:**

Ao efetuar login no **Repasys**, o usuário será direcionado automaticamente para nossa página inicial. Esta página lhe permitirá acessar todas as opções do sistema forma aberta, como uma lista, conforme indicado na imagem abaixo:

![inicio-pagina-inicial](./assets/paginaInicialLista.png)

Também é possível acessar de forma tradicional através da navegação pelos menus:

![inicio-pagina-inicial](./assets/paginaInicialMenus.png)

Uma terceira opção de acesso aos menus é possível através da barra lateral, no canto esquerdo da tela, conforme demonstrado abaixo:

![inicio-pagina-inicial](./assets/menu_esquerdo.png)

![inicio-pagina-inicial](./assets/menu_hamburguer.png)
