O relatório de movimento conta analítico possibilitara a visualização da movimentação bancaria das contas cadastradas. 

Para acessar o relatório de movimento de conta analítico, clique no menu Financeiro>Relatórios>Movimento Conta Analítico

![image.png](./assets/image-65.png)

Na tela de filtro insira os dados para que o sistema realize as buscas.

![chrome_Ns6fawmkQo.png](./assets/chrome_Ns6fawmkQo.png)

1. **Tipo de Lançamento:** Indique o tipo de lançamento
2. **Data:** Indique as datas desejadas.
3. **Conta Corrente**: Indique a conta corrente.
4. **Operação**: Indique o código de operação.(opcional)
5. **Consultar:** Clique em consultar para o sistema iniciar o processamento do relatório. 

No bloco da tela relatório movimento conta analítico será exibido os resultados conforme os dados preenchidos no filtro.
O Sistema irá exibir o resultado em tela como também tendo a possibilidade de exportar o resultado para Excel ou impressão.

![chrome_X3uUyb3s65.png](./assets/chrome_X3uUyb3s65.png)

1. **Exportar:** Clique em exportar para o sistema exportar pra o formato Excel.
2. **Imprimir:** Clique em imprimir para o sistema processar o formato de impressão.
