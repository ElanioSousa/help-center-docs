O **relatório analítico** é um documento que apresenta, de forma detalhada e estruturada, uma análise profunda de um determinado conjunto de dados, informações ou situações. Seu objetivo principal é fornecer uma visão crítica sobre o tema abordado, considerando diferentes perspectivas e fatores que possam influenciar o assunto em questão.

Para acessar o relatório de titulo analítico, clique no menu Financeiro>Relatórios>Título Analíticos 

![image.png](./assets/image-64.png)

Na tela filtros insira os dados desejados para que o sistema processe as buscas retorne o relatório conforme especificações.

![chrome_3HrVQex7vT.png](./assets/chrome_3HrVQex7vT.png)

1. **Cliente:** Indique o nome do cliente.
2. **Tipo**: Indique o Tipo (ex. Receita, Despesa, Outros)
3.  **Situação:** Indique  a Situação (ex. Aberto, Baixado, Cancelado).
4. **Categoria:** Indique a categoria.
5. **Forma de Pagamento**: Indique a forma de pagamento(ex. A prazo, Cheque, Dinheiro).
6. **Empresa:** Indique a empresa.
7. **Data de vencimento:** Indique a data de vencimento.
8. **Data Pagamento:** Indique data de pagamento.
9. **Conta Corrente:** Indique a conta corrente.
10. **Operação:** Indique código de Operação.
11. **Consultar:** Clique em consultar que o sistema irá processar o relatório.

**Relatório de títulos**

No bloco da tela relatório de títulos será exibido os resultados conforme os dados preenchidos no filtro.
O Sistema irá exibir o resultado em tela como também tendo a possibilidade de exportar o resultado para Excel ou impressão.

![chrome_ZG6GA9yUlk.png](./assets/chrome_ZG6GA9yUlk.png)

1. **Exportar:** Clique em exportar para o sistema exportar pra o formato Excel.
2. **Imprimir:** Clique em imprimir para o sistema processar o formato de impressão.
